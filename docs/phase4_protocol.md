# Phase 4 frozen simulation protocol

**Freeze** Prepared after WP 3.3 and pre-launch audit repairs (`bw-phase4-v2`). This release has 8,654 assigned jobs across 18 Colab shards. The protocol hash includes all executable sources and configurations. JSON-formatted YAML files in `configs/` are the authoritative settings. Values computed by the separate pipeline fixture cannot enter this protocol.

## Causal estimands and design

For each evaluation query the primary error is the square root of the equally weighted mean over the fixed query set of the sum of the squared BW errors of the two arm-specific barycenters. Label this finite-grid two-arm BW PEHE. It does not measure individual counterfactual contrast error. Report exact query-level worst error, leading projector contrast RMSE, leading eigenvalue contrast MAE, interior transport contrast RMSE where defined, and positive-reference bulk eigenvalue ratios. Only complete query families contribute to the primary PEHE, and every attempted run and fit remains in failure counts. A partial complete-query error is a diagnostic. All methods use the same outcomes, treatment draws, covariates, query weights and seed stream within each cell.

### Conditional matrix laws

Crossover outcomes use continuous uniform covariates, a linear logistic treatment model and matrices `Y = G B_a(X) G`. The six equally weighted queries are declared in the configuration. The leading spike `κ` is placed in coordinate 0 and a unit reference bulk mode in coordinate 1 so `(0, 1)` rotation rotates the spike directly into the bulk with effective ratio `κ`, with nonlinear regime heterogeneity in `x1` and `(x1, x2)` scaling. Centered, Gaussian symmetric transport perturbations are normalized by their Frobenius norm and have mean zero. Adding the identity gives a positive-definite action and exact interior BW root via the score identity. The fixed noise amplitude is 0.48, reduced to 0.16 only in the frozen stochastic-recovery scenario. The commuting positive control uses diagonal covariances and independent mean-one diagonal transport perturbations. The spiked mechanism scenarios use a varying rotation up to 60 degrees.

Here `condition` or κ is a spike-to-unit-reference-bulk ratio before covariate and treatment scaling. Changing a separate near-zero lower eigenmode changes the matrix’s actual condition number. Each record preserves the minimum true eigenvalue, maximum true condition number when interior, and observed rank range. Positive floor settings fix the smallest root eigenmode at the declared floor. The crossover’s zero-floor branch uses a fixed interior root floor of 0.02 and ensures singular observed outcomes with normalized random rank-`p−1` projectors of mean identity. This tests observed rank deficiency. The separate structural diagnostic has a common null direction and truly singular arm roots. Its results mark a scope boundary and do not enter the primary interior-root superiority or coverage scorecards.

The confirmatory strict null has five prespecified strata and nonlinear treatment probabilities within each. Covariance laws are identical across arms given covariates, and conditional means of the BW transport scores are constant within strata. The coverage DGP likewise has five fixed strata with mild propensity overlap stress and three market/sector-style eigenmodes, rotating both the `(0, 1)` plane and the rank-3 boundary `(2, 3)` plane so the rank-3 projector contrast is genuinely non-null whenever the eigengap is positive. Its outcome action is a mean-identity transport with amplitude 0.35. It estimates contrasts between the two subgroup barycenters directly. Continuous-query PEHE uses forest weights and may contain localization bias. No continuous-query coverage guarantee is invoked.

### Misspecification and measurement

DGP 7 has six equiprobable covariate cells, formed by two strata and three hidden-in-the-misspecified-model levels. The outcomes are deterministic conditional on arm and cell. The covariate basis with interactions represents all six conditional means of every tested covariance score. Correct outcome branches fit ridge `1e-8` with an unpenalized intercept to that saturated basis. Missing empirical arm/cell support, finite-sample errors, and root failures remain part of the evaluation. Wrong outcome branches use only the stratum indicator. The correct propensity diagnostic uses the exact assignment table, and wrong propensity uses 0.5 throughout. The table is a controlled diagnostic using one oracle nuisance, distinct from ordinary fitted-method PEHE and coverage. The subgroup target equally mixes the three cell covariances within each stratum and is calculated by a high-tolerance nonnegative BW solve. Report Monte Carlo mean signed contrast bias, contrast RMSE, all larger sample sizes, and the log-RMSE versus log-n slope. The no-cross-fitting diagnostic intentionally reuses the same rows for outcome score fitting and evaluation, separate from the honest primary fit.

DGP 8 samples zero-mean Gaussian vectors with a unit-varying latent covariance and uses the uncentered `ZZᵀ/T` covariance report. T=8 falls below p=10, so every report is rank deficient. The primary reference is a fixed independent Monte Carlo BW barycenter per arm/stratum using 4,096 draws per reference. This differs from the analytic latent root for finite T. A split-reference maximum BW discrepancy and separate latent-root error describe integration uncertainty and measurement distortion. Deterministic exact-margin comparisons use the same numerical target across methods. The collector checks matching target eigenvalues and seven fixed normalized quadratic probes per covariance up to absolute `1e-8` and relative `1e-9` tolerances across VMs. Raw byte hashes remain available for provenance. Inspect reference-half disagreement where it is comparable to the margin before drawing a conclusion.

## Estimation and fair comparisons

All fitted methods use the same 15/35/50 anchor/design/evaluation split, three cross-fitting folds, and design-only learned partitions. A held-out control anchor uses the Phase 3 rules. Forest methods share the design configuration (200 trees, minimum leaf 12, depth five and fixed feature/cutpoint budgets). RFWLFR allocates the common 200-tree budget to each arm and uses direct BW Fréchet split loss at the two-means proposal as implemented in Phase 3. Its larger computational budget is reported. The global and local T-learners are separate comparisons. The global T-learner evaluated at subgroup marker queries is descriptive and is not generally a subgroup mixture estimator. No treatment-outcome fitting or tree tuning uses test queries.

Use the fitted square-root, log-Euclidean, log-Cholesky, and elementwise embedding forests. Both log methods are tuned on the same three prespecified ridge values `1e-6, 1e-4, 1e-2` using an independent validation sample of 72 observed factual outcomes. The tuning score is the inverse-propensity-weighted factual BW squared loss using design-only logistic predictions on that validation sample. Fits are never updated after validation. The default `1e-6` instances are retained. The common split, nuisance family and forest settings are fixed for all methods, with validation searches correcting the boundary-sensitive ridge choice. The scaling profiles use the frozen default ridge and omit ridge selection time.

Ablations include Layer A with learned anchor and with identity anchor. The latter reuses the bitwise-equivalent square-root row. Compare Layer A to Layer B on the same learned localization, and compare full roots under learned and identity splitting to isolate partition effects. Additional comparisons include the one-step update, unaugmented and IPW intrinsic variants, entropy calibration, and the Phase 2 near-boundary failure accounting. The oracle row is a labeled truth reference only.

## Coverage and runtime

Joint 95% coverage uses 999 shared Gaussian multipliers over all five strata and the 25-member declared family of matrix contrasts, the three top eigenvalue contrasts, and the rank-three projector contrast. Both arms’ dimensionless Kato/Rayleigh-Schrödinger mixing guard is held fixed. A failure or abstention makes the declared family uncovered in that replicate. At a true exact eigengap tie, the full family is unidentified and its coverage is omitted, while matrix-only and identifiable-eigenvalue results remain informative. In the strict null distinguish rejection of zero by an available band from the separate failure to cover due to abstention. Report Wilson Monte Carlo intervals, band widths, and abstention counts. Compare pointwise BW multiplier bands and square-root/elementwise/log cutoffs with plug-in spectral derivatives. Their coverage is measured against BW truth, so embedding target bias can remain even with a calibrated transformed-mean interval.

Scaling profiles are isolated runs measuring fit, point prediction, influence construction, bootstrap and peak process RSS. The embedding and BW methods use one frozen query for timing inference. Non-DR T-learners report no inference timing. Every scaling job uses a single thread and a separate process, and uses a 30-minute timer per method. Report the threshold cell p=20, n=500 and the additional p=30, n=1000 cell along with full scaling. Timeout is a measured censored failure, not omitted. A target below five minutes and four GiB on one worker is sufficient for that part of the six-core plan. Timing across VMs is an estimate, with actual hardware variation retained. Large scaling runs are isolated in four notebooks.

## Decision rules

- The Gate G3 register eligibility uses κ≥20 and rotation ≥30 degrees or floor ≤1e-4. Section 8.1’s mechanism filter uses κ≥50 and rotation ≥30 degrees. For each report all eligible cells, a seed-blocked equal-cell aggregate, and a separate realistic aggregate restricted to κ≤100. The latter excludes the extreme κ=150 cell. The mechanism and realistic-register aggregates are prespecified evidence for a broad GO. Each cell and aggregate reports actual comparison pairs, per-method and paired MC uncertainty, and failures.
- On complete 50-seed paired aggregates require at least 15% lower mean PEHE versus square-root, at least 30% lower versus each tuned log-Euclidean and elementwise, non-overlapping 95% Monte Carlo intervals and relative BW MCSE below 2%. Clinical or applied significance still depends on the mechanism and relevant DGP. Report every competing method and the strongest method in each cell. Compare the same-weights Layer A ablation to intrinsic Layer B before attributing a gain to geometry. A gain that vanishes at κ≤100 or only arises from the tree partition is insufficient for a broad GO.
- Full-family null coverage and all supported coverage cases with n≥500 and gap≥0.5 use the [0.92, 0.98] empirical screen. Report severe undercoverage below 0.85 or extreme overcoverage above 0.995 at n=1000 as the registered falsifier, and strict null rejection above 0.10. Only the rank-deficient observation branch with positive target enters the boundary success regime. Count every failed guard in that regime and report tuned-log gain with finite-T error. A rank-deficient observation crash, nonfinite accepted fit or PSD violation fails that stability check. Fallback is never counted as a successful root.
- Interpret an advantage confined to spectral inference or extreme near-singularity (floor ≤1e-5) against the PIVOT branch. If gains remain under 5% over square-root throughout the realistic cells, report INCREMENTAL-ONLY unless the separate spectral/boundary case warrants PIVOT. Fair baseline dominance, failure to recover, and the registered severe coverage failures trigger KILL review. Phase 5 is conditional on a concluded GO or approved PIVOT. No fixture is eligible.

The collection script generates paired cell tables, bias/rate tables, coverage tables, scaling exponents and an evidence sheet. The separate Gate G3 memo still requires scientific interpretation of failures, uncertainty and ablations after collection. Data-dependent changes would require a new protocol signature and a separate exploratory label.
